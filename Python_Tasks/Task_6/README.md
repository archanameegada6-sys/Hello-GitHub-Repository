# Python Task 06 – HackerRank Coding Practice

This folder contains solutions to 20 HackerRank Python problems.

## Topics Covered
- Conditionals and loops
- Arithmetic operators and division
- Functions, strings, lists, and tuples
- Set operations and mutations
- Regular expressions
- Sorting and frequency counting

## Files
Solutions are saved as `problem1.py`` through `problem20.py`.
Each file includes the problem name and HackerRank link.

## Note
These are reference solutions. Run and submit each solution on HackerRank to confirm acceptance before submitting the task.
